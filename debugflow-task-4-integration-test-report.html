10 · Commands to Run DebugFlow Locally

Prerequisites

  • Python 3.11+ with the backend/.venv virtual environment already created
  • Node.js 18+ on PATH (installed at C:\Program Files\nodejs on this machine)

Terminal 1 — FastAPI backend (port 8000)

cd backend
.\.venv\Scripts\python.exe -m uvicorn main:app --reload --port 8000

Terminal 2 — React/Vite frontend (port 5173)

# Windows — add Node to PATH first if not already on it
$env:PATH = "C:\Program Files\nodejs;" + $env:PATH
cd frontend
node_modules\.bin\vite.cmd           # dev server

# Or for a production preview:
node_modules\.bin\vite.cmd build
node_modules\.bin\vite.cmd preview

Run backend tests only

cd backend
.\.venv\Scripts\python.exe -m pytest tests/ -v

Open the app

http://localhost:5173

Workflow

  1. Click Load Demo in the Python Source Code panel
  2. Click a demo error button (ZeroDivision / NameError / IndexError) in the Traceback panel
  3. Click Analyze Bug → Root Cause Analysis panel appears
  4. Click Generate Fix → → Proposed Fix panel appears with Unified Diff / Original / Fixed tabs
  5. Click Apply Fix to Editor to copy fixed code into the editor (explicit action)
  6. Click Load Demo Tests in the Test Runner panel
  7. Click Run Tests → PASS/FAIL result with counts and output
